# ScootPit BMS 1.6.7

- Die Fahrtkachel zeigt nun ein Pausensymbol und öffnet ein Kontextmenü für **Fahrt pausieren**, **Fahrt fortsetzen** oder **Fahrt beenden**.
- Das Beenden einer Fahrt muss zusätzlich bestätigt werden.
- Eine manuell pausierte Fahrt lässt sich erst fortsetzen, wenn der BMS-Lastausgang eingeschaltet ist.

Die signierte APK kann über die bestehende Installation installiert werden. Scooter-Profile, Zähler und gespeicherte Fahrten bleiben erhalten.
